# terence-egbelo.com

Personal site. Static HTML and CSS, no framework, no build step.
Served by GitHub Pages from the default branch.

```
index.html      landing
about.html      about
writing/        posts
style.css       all styling
CNAME           custom domain for GitHub Pages
```

To add a post: copy an existing file in `writing/`, replace the body and the
meta tags, then add an entry to the Writing list in `index.html`.
